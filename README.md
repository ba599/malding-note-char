# malding-note-char

게임 캐릭터 데이터를 JSON으로 관리하는 저장소. 현재 블루 아카이브 캐릭터 데이터를 포함하고 있으며, 웹 에디터로 편집할 수 있다.

## 에디터 실행

```bash
cd editor && node server.js
```

[http://localhost:3000](http://localhost:3000) 으로 접속.
